# Unity Treasure Hunt

A 3D game built in Unity as part of a university team project. The project was developed collaboratively using C# and Unity, with a focus on game mechanics, player interaction, and progression systems.

## Features

- 3D player movement
- Custom game map and environment design
- Collectible items and inventory management
- Player progression system
- Interactive objects and game mechanics
- Glider object and movement mechanics

## Technologies

- Unity
- C#
- Git
- GitHub

## My Contributions

My main contributions to the project included:

- Implementing player movement and movement-related mechanics
- Designing and building parts of the game map
- Creating and designing the glider object
- Developing the inventory system
- Contributing to the player progression system
- Testing and debugging gameplay features

## Team Project

This project was originally developed collaboratively for a university software engineering course.

This repository is a fork of the original team repository.

## Running the Project

1. Clone the repository
2. Open the project in Unity
3. Open the main game scene
4. Press **Play** in the Unity editor
